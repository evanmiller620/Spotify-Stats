Edit the numbers in a stats data file

Open the Spotify-Stats project folder. Pick the data file to edit, search for a song, and change its plays, listening time or skips for any month. Save writes the data file and keeps your changes in a small file in edits/, so they're applied again when you rebuild from a new Spotify export (python3 build.py … --edits edits/<file>.json).

Works in Chrome or Edge. In other browsers you can open the file directly; Save then downloads the two files for you to put in place.

    Your edits

      Edits change plays, time and skips everywhere they're counted: totals, top lists, the library, trends and skip stats. Day-by-day charts (calendar, time of day, daily listening) and devices come from separate day totals and don't change.
